# 已知限制

- Windows 调度不是硬实时，调度误差会受 DPC/ISR、CPU 竞争、节能和虚拟化影响。
- 全局过滤会影响所有普通非 loopback TCP/UDP 流量，无法按进程排除系统服务或单个应用。
- 分片流量、ICMP、ARP、loopback 和 WinDivert impostor 封包不处理。
- 产品不重算 IP/TCP/UDP 校验和，因为封包正文和头部均不修改；若未来修改封包则必须另行设计。
- 强制终止时用户态队列中的封包不可恢复；只有正常 StopAndFlush 可保证尝试放行。
- CSV 是诊断功能，慢磁盘时允许丢 CSV 记录但不阻塞网络路径。
- 本机 localhost 无法验证产品延迟；真实 Inbound 验证需要第二台机器或桥接虚拟机。
- 当前原型没有安装器、代码签名、自动更新或开机自启。
- 未实现 PID/五元组映射、游戏识别、协议识别或任何反作弊相关功能。
